## ZuluIDE - The Parallel ATA/IDE Optical Disc Emulator for everyone - Available Now
![ZuluIDE V2](https://www.zuluide.com/assets/img/ZuluIDE-V2-2.5in-dual-Rev-2026a-topDown-with-CD-Audio-Header-web.jpg)

[ZuluIDE™](https://www.zuluide.com) is a family of IDE/ATAPI computer storage emulation devices, developed by Rabbit Hole Computing, the creators of ZuluSCSI. VHD's, BIN/CUE files, and ISO image files are stored on a standard FAT32 or exFAT-formatted SD card. 

ZuluIDE V2 hardware can be purchased [directly from Rabbit Hole Computing](https://shop.rabbitholecomputing.com/collections/zuluide), or via its [network of resellers](https://www.zuluide.com/wheretobuy)

ZuluIDE V2 supports dual device mode, and can _simultaneously_ emulate up to two ATA/IDE devices at the same time, including:

* IDE/ATAPI CD-ROM drive. Images can be any size, including multi-gigabyte DVD-sized images.
* Iomega Zip 100 drive.
* Rigid HDD emulation.

### Supported transfer modes with ZuluIDE V2
ZuluIDE V2 supports the following transfer modes:
* Ultra DMA transfer modes modes 0-2 (up to ATA/33). 80-conductor cables are not required for ATA/33.
* Multi-word DMA modes 0-2, with the [latest firmware](https://github.com/ZuluIDE/ZuluIDE-firmware/releases/latest)
* Programmed I/O modes 0-3
